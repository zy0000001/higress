======================================================================================
===================================项目构建======================================
======================================================================================
# 克隆代码
git clone https://github.com/zy0000001/higress.git --recurse-submodules
# 进入项目
cd higress
# 先拉取最新的子模块配置
git submodule sync
# 重新拉取子模块代码
git submodule update --init --recursive --force
# 先清理旧的依赖缓存
go mod tidy
# 将mod中的external替换为envoy或者istio，具体目录见git submodule sync输出
